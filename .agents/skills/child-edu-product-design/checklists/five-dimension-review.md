# 📋 五维设计与代码交付自查检视表 (Five-Dimension Review Checklist)

> **使用说明**：在每次功能方案策划、UI 改版、组件重构或提交 Pull Request 之前，必须逐一核对以下 5 个维度的 25 项检验指标，确保无遗漏。

---

## 维度一：🍎 小学语文名师检视 (Teacher Review)

- [ ] **1.1 课本同步对齐**：生字与题库严格对应部编人教版教材当前课次，没有超纲或错字。
- [ ] **1.2 识写分流明确**：明确区分“会认字表”与“会写字表”，没有对会认字进行强行死记硬背默写考核。
- [ ] **1.3 现代汉语国标笔顺**：笔画动画及判定严格遵循国标规范（先横后竖、先撇后捺、从上到下等），无倒插笔。
- [ ] **1.4 笔画名称准确**：伴读语音播报的笔画名称符合规范（如“横折弯钩”、“竖折折钩”、“竖提”准确区分）。
- [ ] **1.5 语境与例句生活化**：拼音有标准声调，生字均配有常用生活化组词和简短例句。

---

## 维度二：🎓 最专业教育者检视 (Educator Review)

- [ ] **2.1 脚手架梯度完备**：严格提供“观摩演示（扶）$\rightarrow$ 描红纠偏（半扶）$\rightarrow$ 独立自测（放）”的进阶路径。
- [ ] **2.2 外在认知负荷极简**：界面单一时刻只有一个核心任务，没有杂乱多余的动效干扰儿童注意。
- [ ] **2.3 间架结构空间引导**：田字格、米字格辅助线清晰，横中线、竖中线定位明确。
- [ ] **2.4 艾宾浩斯抗遗忘闭环**：练习中写错或偏离的字能顺畅沉淀进错题本，并提供针对性重练。
- [ ] **2.5 启发式自省机制**：错题展示时能清晰指出是“笔顺错”还是“起笔偏离”，引导孩子自己观察对比。

---

## 维度三：🧸 儿童心理学专家检视 (Psychologist Review)

- [ ] **3.1 零刺耳否定与零侮辱**：绝对没有尖锐警报音、血红大叉（❌）、扣分或嘲讽批评文案。
- [ ] **3.2 温和纠偏与软着陆**：写错时采用笔画微震、柔和发音或正确起笔微光提示，呵护自尊心。
- [ ] **3.3 毫秒级即时正向反馈**：每一笔写对有悦耳水滴/木鱼声；通关有星星、墨滴和庆祝礼花。
- [ ] **3.4 成长型思维内驱力**：积分和成就（徽章墙）奖励的是“努力与坚持”，而不是单纯惩罚失误。
- [ ] **3.5 20分钟视力健康保护**：护眼防疲劳机制保持激活，连续使用 20 分钟能友好弹窗引导眼部放松。

---

## 维度四：🎨 儿童 UI 交互设计师检视 (UI/UX Designer Review)

- [ ] **4.1 超大触控热区**：所有操作按钮点击区域 $\ge 48\text{px}$，核心大按钮建议 $56\text{px}\sim 64\text{px}$。
- [ ] **4.2 触控间距防误触**：按键之间边距 $\ge 12\text{px}$，破坏性操作（清空、重置）有二次确认防呆。
- [ ] **4.3 护眼米黄书香调色**：底色温润不反光（amber-50/stone-50等），不用刺眼荧光色，对比度达标。
- [ ] **4.4 字体与排版清晰度**：汉字字号大，楷体/规范规范印刷体展示，拼音声调字符居中对齐。
- [ ] **4.5 多通道感官协同**：视觉（字形+动画）、听觉（普通话+自然音效）、触觉（移动端细腻震动）同步到位。

---

## 维度五：💻 资深产品架构工程师检视 (Engineer Review)

- [ ] **5.1 60fps 丝滑书写体验**：手写 Canvas/SVG 笔迹延迟 $<16\text{ms}$，触控事件不触发全组件树重绘。
- [ ] **5.2 离线优先 100% 可用**：教材题库、汉字矢量数据、音频音效全部本地加载，断网仍可完整练习。
- [ ] **5.3 跨端容器与安全区**：适配移动端全面屏 safe-area-inset，兼容 Capacitor Android / iOS 原生手势。
- [ ] **5.4 防御性编程与自愈**：`localStorage` 读写带有错误捕获与 Schema 默认兼容，TTS 音频受限自动降级。
- [ ] **5.5 代码整洁与可维护**：TypeScript 类型严格（无 `any`），通过 `oxlint` 检查，无多余未引用依赖。
