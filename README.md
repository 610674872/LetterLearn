# 《字小乐》(LetterLearn) - 人教版部编小学语文汉字学习与智能听写 App

一款完全对接**教育部统编义务教育语文教科书（人教版/部编版）**，专为 5~10 岁小学生及学龄前儿童研发的汉字规范书写与听写辅导应用。

---

## 🌟 核心功能特色

### 1. 规范笔顺与田字格练字 (防倒笔纠偏)
* **动态笔顺分解演示**：严格遵循国家语言文字工作委员会现代汉语通用字规范笔顺，逐笔动画展示，带慢速回放。
* **笔画名称语音伴读**：动画演示时，同步播报笔画名称（如“横”、“竖”、“撇”、“捺”、“横折弯钩”）。
* **三阶递进训练法**：
  * **1. 看演示**：观察起笔位置与笔画顺序。
  * **2. 去描红**：浅灰底模引导，手指/手写笔在田字格描红，实时监测起笔顺序与方向，写错即时温和提醒。
  * **3. 默写**：无底色自主书写，完成后评分并根据正确率奖励星星（⭐）。

### 2. 看拼音写汉字
* **语境化出题**：展示带声调的标准拼音与课文例句（如 `[tiān kōng] 蓝蓝的 (天空)`）。
* **标准普通话朗读**：可点击发音按钮倾听读音。
* **屏幕手写直接作答**：在田字格中完成规范汉字书写，答对触发彩带与鼓励语音。

### 3. 智能人教版同步听写系统
针对家长每天辅导生字作业耗时耗力的痛点，提供双场景方案：
* **纸上伴读听写模式 (保护视力推荐)**：
  * 孩子在纸质作业本上用铅笔写字，App 充当“AI 报听写老师”。
  * 支持自定义每词朗读遍数（1遍 / 2遍带例句）与停顿间隔（6秒 / 8秒 / 12秒 / 15秒）。
  * 播报完毕提供快速批改清单，家长一键勾选正误。
* **屏幕手写自测模式**：
  * 孩子直接在屏幕双田字格上手写词语，系统自动评判并汇总成绩。

### 4. 艾宾浩斯错题强化与儿童健康关怀
* **错题本自动归集**：在笔顺练习或听写中写错的字自动收录至错题本，支持一键针对性重练。
* **正向游戏化激励**：星星徽章（⭐）与墨滴（💧）成长体系。
* **护眼防疲劳机制**：每隔 20 分钟自动弹出“小恐龙眼保健操”提醒，保护儿童视力。
